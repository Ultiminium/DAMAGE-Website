DAMAGE

v8.0 — Native Rust

DAMAGE is a programming language designed around how you naturally think. Every feature was built to remove the distance between your logic and working code.

It runs as a single native binary with zero dependencies. Programs are written in .damg files and executed with the damage command.

Note: DAMAGE is intentionally typeless. There are no int, string, or float declarations. Everything is a value.

Key concepts

  • Every block opens with @function+ and closes with @-
  • Content inside a block is indented 5 spaces
  • Anything after | on a line is a comment
  • Variables are referenced with (name) — paren depth matches function position

A complete program

| A simple DAMAGE program
@var+
     name+World-
@-

@print,var+
     +Hello, (name)!-
@-

Installation

Get DAMAGE running on your machine

Download the binary

The easiest way is to download the pre-built binary from GitHub Releases.

chmod +x damage
sudo mv damage /usr/local/bin/damage
damage --version

Build from source

Requires Rust to be installed.

git clone https://github.com/Ultiminium/DAMAGE
cd DAMAGE/damage-rs
cargo build --release
sudo mv target/release/damage /usr/local/bin/damage

Verify

damage --version
# DAMAGE v8.0.0

Hello World

Your first DAMAGE program

Create a file called hello.damg:

@print+
     +Hello, World!-
@-

Run it:

damage hello.damg
# Hello, World!

Blocks

The core structure of DAMAGE

Everything in DAMAGE is a block. A block opens with @functionname+ and closes with @-. Content inside is indented exactly 5 spaces.

@functionname+
     content goes here
@-

Multi-function blocks

Combine functions with commas. The position of each function determines the paren depth for references:

@print,math,var+
     +((score)) (+) 1-
@-

print = position 0 (no parens), math = position 1 → (+), var = position 2 → ((score))

Tip: DAMAGE is forgiving about paren depth. If a name matches a known variable, it resolves regardless of depth.

Block closers

SyntaxMeaning
@-Normal close
@-&Close and chain to next block
@-#End of chain
@---Close a user function definition

Comments

| This whole line is a comment
@print+
     +Hello- | inline comment
@-

Variables

Storing and using values

Declaring variables

@var+
     name+Alice-
     score+100-
     isAlive=1
@-

Booleans use = instead of +value-. 1 is on, 0 is off.

List variables

A variable with commas — useful for displaying a group of things in one call:

@var+
     items+apples,bananas,milk-
@-

@print,var+
     +Shopping: (items)-
@-

Reassigning variables

@dyn,var+
@dyn:(score) = (score)+10
@-

Supports math expressions and copying from other variables:

| copy one variable into another
@dyn,var+
@dyn:(backup) = (score)
@-

Print

Outputting text

Basic print

@print+
     +Hello world-
@-

With variables

@print,var+
     +Hello (name)!-
@-

With math operators

@print,math+
     +2 (+) 2 = 4-
@-

Inline math evaluation with %

Define the expression between %%. The result is placed at the next standalone %:

@print,math+
     +2^10 = %2^10%? The answer is %-
@-
# Output: 2^10 = ? The answer is 1024

Random OR

Use ? to pick one option randomly:

@+Good job!-?@+Well done!-?@+Amazing!-

Multi-statement with &

if, (score) = 100
     @+Perfect!-&@+Top score!-&@+Well done.-

Math

Calculations and expressions

Standalone math block

@math+
     10 + 5
@-

Operators

OperatorMeaningIn print
+Add(+)
-Subtract(-)
*Multiply(*)
/Divide(/)
^Exponent(^)

Exponents

Exponents follow right-to-left convention like standard math:

2^3^2 = 512   | = 2^(3^2) = 2^9

Large numbers

Results above 10^10 automatically display in scientific notation. Results too large to compute return too large to display.

2^34 = 1.718x10^10
10^80 = 10^80

Conditions

if, other if, other

Basic if

if, (score) = 100
@print+
     +Perfect!-
@-

if / other if / other

First match wins — once a branch fires, the rest are skipped:

if, (score) = 100
@print+
     +Perfect!-
@-
other if, (score) > 50
@print+
     +Not bad.-
@-
other,
@print+
     +Keep trying.-
@-

Operators

OperatorMeaning
=Equals
<Less than
>Greater than
~Not equal

Chained AND conditions

if, (score) = 100,(lives) > 0,(name) = Alice

All conditions must be true for the branch to fire.

Loops

Repeating blocks

Fixed count

@loop,print+
     +Hello!-
@loop:5
@-

Variable count

@var+
     times+3-
@-

@loop,print+
     +Hello!-
@loop:(times)
@-

Conditional count

@loop,print+
     +Hello!-
if, (score) = 5
@loop:3
if, (score) ~ 5
@loop:0
@-

@loop:0 skips the loop entirely.

User Input

Getting input from the user

Basic input

@user,print+
     +What is your name?-
@var:create+name-
@-

@var:create stores the input as a variable. Default is 0 if the user types nothing.

Input validation

Keep re-prompting until the user gives valid input:

@user,print+
     +Enter a number:-
@user:expect"n"
@var:create+num-
@-
ValueExpects
"n"Numbers only (integers and decimals)
"l"Letters only

Random

Picking values randomly

From a list

@print,random+
     @()+1,2,3,4,5-
@var:create+pick-
@-

From a range

@print,random+
     @()+1-100-
@var:create+pick-
@-

From variables

@print,random+
     @()+((score)),((lives)),((gold))-
@var:create+pick-
@-

Random OR

Inline — picks one of the options randomly:

@+Good job!-?@+Well done!-?@+Amazing!-

Functions

Defining and calling reusable blocks

Defining a function

@addfunc+
@print+
     +Hello from my function!-
@-
@addfunc:createname"greet"
@---

Calling a function

@greet+
@-
Note: Functions are saved as .func files in the usrfunc/ directory next to the binary. Variables are shared between caller and function. You cannot name a function the same as a built-in.

Fetch

Universal data pipeline

Fetch pipes data from anywhere to anywhere using $. The left side is the source, the right side is the destination.

Syntax

@fetch+
fetch.+source-$+destination-
@-

Reference types

ReferenceMeaning
@var/nameA DAMAGE variable
gui:1A GUI element by ID
/path/to/file.txtA file on disk
@funcnameOutput of a user function

Examples

@fetch+
fetch.+@var/score-$+@var/backup-   | var → var
fetch.+gui:1-$+@var/input-        | gui → var
fetch.+@var/name-$+/tmp/out.txt- | var → file
@-

Text Operations

String manipulation with @text

Get length

@text+
@text:length+@var/name-
@var:create+len-
@-

Also accepts /file/path and @user as sources.

Capitalize a letter

@text+
text:capital"@var/name/s":1
@-

Capitalizes the letter s at position 1 in the variable name.

Lowercase a letter

@text+
text:lower"@var/name/S":1
@-

Max length

@text+
text:maxlength"15"
@-

Errors if the last input exceeds the limit.

Check type

@text+
@text:length+@var/input-
text:check"n"
@var:create+isnum-
@-

Returns 1 if valid, 0 if not. "n" = numbers, "l" = letters only.

Encryption

@enc and @dec

Important: DAMAGE never stores your password. It's used only to generate the encryption seed, then forgotten.

One-way encryption

@enc,var+
     +(password)-
@var:create+encrypted-
@-

No password means no decryption. The data is permanently encrypted.

Two-way encryption

@enc,var+
     +(password)-
@enc:password"mykey"
@var:create+secured-
@-

Decryption

@dec,var+
     @dec:@var/secured/mykey
@var:create+original-
@-

Wrong password produces garbled output. Attempting to decrypt a one-way encrypted variable throws an error.

GUI

Building windowed applications

Opening a window

@gui,var+
@gui:winname"My App"
@gui:winsize"800:600"
@gui:text+Hello (name)-:pos+100,300-
@gui:input:writableelement:text+Type here...-:1
@gui:pressable"name:Click Me":pos+300,200-
if, pressable+Click Me-:true
     @()+Button clicked!-
@-

Coordinates

Origin is bottom-left. X goes right, Y goes up. Elements without :pos stack top-to-bottom automatically.

Element IDs

Elements are given an ID with :1, :2 etc. Use these with @fetch to read and write values.

Writable elements

@gui:input:writableelement:text+placeholder-:1

Only writable elements can be updated via @fetch.

File Output

Writing to files

@output,var+
     +(result)-
@output:createname"results.txt"
@-

Files are saved to the outputs/ directory next to the binary.

Import

Using code from other files

@import+
     +utils.damg-
@-

Runs another .damg file in the same context. All variables and functions from the imported file are available after the import.

Packages

Extending DAMAGE with community packages

Installing

damage install net

Listing installed

damage list

Removing

damage uninstall net

Installed packages auto-load on every program run. No import needed.

Package format

A package is a folder containing any mix of:

  • .damg — adds DAMAGE functions and variables
  • .py — adds Python-powered built-ins (Python version only)
  • package.json — name, version, description, author

Packages are installed to ~/.damage/install/.

Error Handling

What happens when things go wrong

When DAMAGE encounters an error the program stops immediately and shows:

ERROR:
line.7, error "description"

Save to logs? [y/n]
  • Press y to save the error to ~/damage/logs/damage.log
  • Press n to discard
  • Use -l flag to always save, -n to never save

Common errors

ErrorCause
unrecognised syntaxLine doesn't match any known pattern
