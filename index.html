SYNTAX

Readable by design.

Every block opens with @function+ and closes with @-. Content inside is indented 5 spaces. That's it.

VARIABLES & PRINT
| declare variables
@var+
     name+User-
     score+100-
@-

@print,var+
     +Hello (name)!-
@-
CONDITIONS
if, (score) = 100
@print+
     +Perfect!-
@-
other if, (score) > 50
@print+
     +Not bad.-
@-
other,
@print+
     +Keep trying.-
@-
USER INPUT
@user,print+
     +What is your name?-
@user:expect"l"
@var:create+name-
@-

@print,var+
     +Hello (name)!-
@-
MATH & ENCRYPTION
| inline math evaluation
@print,math+
     +2^10 = %2^10%? Yes, %-
@-

| encrypt a variable
@enc,var+
     +(password)-
@enc:password"mykey"
@var:create+secured-
@-
LOOPS
@var+
     times+5-
@-

| loop a variable amount
@loop,print+
     +Hello!-
@loop:(times)
@-
FUNCTIONS
@addfunc+
@print+
     +Hello from my function!-
@-
@addfunc:createname"greet"
@---

@greet+
@-

INSTALL

Up in 30 seconds.

Download the binary for your platform, drop it in your PATH, and start writing.

01

Download

Grab the latest binary from the GitHub releases page.

github.com/Ultiminium/DAMAGE
02

Install

Make it executable and move it to your PATH.

sudo mv damage /usr/local/bin/damage
03

Run

Write a .damg file and run it.

damage hello.damg
04

Build from source

Have Rust installed? Build it yourself on any platform.

cargo build --release

FEATURES

Everything you need.

Built for people who think in plain logic. No fluff, no gatekeeping.

Native Rust binary

821KB. Zero dependencies. Runs natively on Linux, Mac, and Windows.

Logic-first syntax

Designed around how you naturally think, not how a computer expects input.

GUI support

Build real windowed apps with buttons, inputs, and labels. No extra libraries.

Built-in encryption

Encrypt and decrypt variables with a password. Never stores the key.

Package system

Install community packages with damage install name.

Random built-in

Pick from lists, ranges, or variables. Random OR with ? for natural variety.

Universal fetch

Pipe data anywhere — variables, files, GUI elements — with one syntax.

Clear errors

Errors show the exact line. No stack traces. No cryptic messages.
